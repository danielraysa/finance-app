# Overview
This project is a finance app to manage financial records as they need common finance reports such as balance sheet, cash flow report. Some features such as approval, invoice generations, notifications are needed and to be added if there's not exist. Built using Laravel framework with Inertia.js and Vue as the frontend

## Dev environment tips
- Use `bun` instead of `npm` to install packages/run scripts
- Running tests after done adding/editing all files
